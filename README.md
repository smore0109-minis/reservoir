# 退休資產規劃器

網站：https://smore0109-minis.github.io/reservoir/

本 public repository 只用來發布 PWA；應用版本以網站頁首顯示為準。

Private 原始碼專案的 CI 通過後，會自動建置 PWA、同步完整 `dist/pwa/` 並 push 到 `main`；本 repository 的 GitHub Actions 再發布至 Pages。不要在此處手動編輯 `dist/pwa/`。

設定保存在各自瀏覽器，不會自動跨裝置同步，請使用備份／匯入設定。更新時在同一網址取得更新提示後，關閉所有相關分頁及 PWA 視窗，再重新開啟。
